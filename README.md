# My React Project

This is a React application built using React and React Router.

## Features
- Home page
- Product list
- Product details page
- Cart page
- Login page

## Tech Stack
- React
- React Router
- JavaScript
- CSS

## How to run this project locally

1. Clone the repository
   git clone https://github.com/VENKATESH-diges/my-react-project.git

2. Go to project folder
   cd my-react-project

3. Install dependencies
   npm install

4. Start the project
   npm start
